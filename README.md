Modifikasi 1 — Menambahkan nama pengguna

Pada kode awal belum ada input nama. Sekarang ditambahkan:

<input type="text" name="nama" required>

Kemudian nama ditampilkan pada hasil:

Halo, <?= htmlspecialchars($nama) ?>!

Contoh:

Halo, Budi!
Hasil: 15
